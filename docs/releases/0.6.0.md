# Irelia Companion 0.6.0

A responsiveness and cohesion release. Nothing slow runs where it can freeze the app anymore. Start / Stop fetching always answers. The overlay shows the same matchup and build as the dashboard. The app is reorganised into three tabs, and the Dock is gone.

The installer is per-user (no admin rights), lets you choose the install folder, and creates **Irelia Companion** shortcuts in the Start Menu and on the desktop. It isn't code-signed yet, so Windows SmartScreen will warn on first run: choose **More info → Run anyway**. Installing over 0.5.x keeps your settings, API key and match data in `%APPDATA%\irelia-companion\`.

## What's new
- **No more hangs.**
  - The draft model is built in a thread of its own, and so are draft, live "Next" and your-games requests. Before, building it froze the app for a few seconds, more on a large database, every few minutes while fetching.
  - **Evaluate builds** and **Run data audit** also have their own thread. Before, they ran in the fetching thread, so Start / Stop waited for them, up to a minute.
  - If a background thread ever stops, it starts again by itself. Before, Start / Stop could stay stuck until you restarted the app.
  - Start / Stop answers at once ("Starting…", "Stopping…") and settles when fetching reports back.
- **The overlay follows the dashboard.**
  - There is one matchup for every window: your lane, your lane opponent and both teams. Pick an opponent or a lane in the dashboard, or switch Draft-adjusted / Lane baseline, and the overlay changes with it.
  - In game, the opponent is the enemy in your position. In games without positions (customs, practice tool), it is champ select's pick, which is now kept through the game, else the enemy Irelia faces most in your lane.
  - The lane stats, the threat summary and "Next" all use that same opponent.
  - Your picks hold until the draft and its game are over. **Follow the draft / the game** goes back.
  - The overlay title says which build it shows ("Top · vs Darius · draft-adjusted"). In draft-adjusted mode it shows "Next" with its reason. In lane-build mode it shows the build plan's next item and counter items, so the two never contradict each other.
  - The overlay's build no longer changes mid-game when new games arrive.
- **Three tabs instead of Dock / Draft dashboard.**
  - **Build:** the build for your matchup. In game, a live panel at the top shows CS, vision and gold against your opponent.
  - **Your games:** item timings, what works for you, and the post-game review, side by side, for Top, Mid or both.
  - **Data:** fetching, the patch per region, the draft model with **Evaluate builds**, and maintenance.
  - The Build tab keeps a small Match data card with the Start / Stop button.
- **Builds are pushed, not polled.** The app sends a new build when the matchup, the mode or the data changes, instead of each window asking again. While a new one is on its way, the build dims and says "Updating build…".
- **Removed: the Dock and its streamed OTP scan.** Fetching on every Riot host replaced it in 0.4.0, and its lane builds are the Build tab's. Scan results saved by older versions stay in the database, unused.

## After installing
Nothing to do. Your lane choice moves from the old dashboard to the app's settings by itself. **Evaluate builds** is now on the **Data** tab.
