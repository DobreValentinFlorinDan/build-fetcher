# Irelia Companion 0.5.1

A polish pass over the whole app: the draft-adjusted builds explain themselves more clearly, a few display bugs are fixed, and numbers read the same way everywhere.

## Download

The installer is per-user (no admin rights), lets you choose the install folder, and creates **Irelia Companion** shortcuts in the Start Menu and on the desktop. It isn't code-signed yet, so Windows SmartScreen will warn on first run: choose **More info → Run anyway**. Installing over 0.5.0 keeps your settings, API key and match data in `%APPDATA%\irelia-companion\`.

## What's new
- **Draft adjustments explain each change.**
  - Every changed pick says what it replaces ("Kraken Slayer *instead of* Sundered Sky").
  - It also says how much better it does than the lane pick in this draft ("+2.1 pts vs the lane pick", or "About the same").
  - The evidence line now reads "121 games · 90 pilots · 43 like this draft". It no longer shows more pilots than games; the full 95% interval is in the tooltip.
  - Summoner spells, shards, skills and starting items show their icons instead of an empty square.
  - The draft's stand-out traits are plain labels ("Lane opponent magic damage 12% · LOW") instead of chips that looked like dropdowns.
  - Regions use their usual names (KR, EUW, EUNE, NA, JP), sorted by games. A left-out region is struck through.
  - The evaluation status says what it means for you ("the lane baseline stays the default until it is"), without a command line.
- **Skill path:** each level is coloured by its skill again. The E row's numbers were invisible (dark on dark).
- **Game counts** are whole numbers ("≈210 games", not "209.7 Matches") on every card. Boots now show their names, and repeated starting items show as one icon with ×2.
- **Match Database:** while fetching, the status is one summary line ("Checking players on 5 of 5 servers · fetching matches in 3 of 3 regions") instead of every host's task in a row. The stray "idle" line is gone, and all counts use the same number format.
- **Your games:**
  - Item timings are a small table: you, the high-elo median, and the difference (faster in green).
  - Past games list the result, the opponent's portrait and a short date.
  - The review lines up the same way.
- **In game:** the overlay's adjusted "Next" item shows how much gold is left to buy it (its price minus the components you own). The Live Game card shows "Next" as its own block.
- **Smaller fixes:**
  - The client phase reads "Champ select" / "In game" instead of "ChampSelect" / "InProgress".
  - The draft dashboard's note describes the build it shows.
  - The Dock no longer shows "g" (gold?) for games, and its header no longer says "adjusted for this draft".

## After installing
Nothing to do. If you haven't yet, press **Draft dashboard → Evaluate builds** once to see whether the draft-adjusted builds beat the lane builds on your games.
