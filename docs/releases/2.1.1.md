# Irelia Companion 2.1.1

**2.1.1 fixes the app freezing when champ select starts: it showed "Match found" and then followed nothing, no champ select, lane opponent, build changes or overlay in the game. The fault has been in the code since 1.0. It needs fetching to be set up and set to pause during games, which is the default.**

## What changed
- **The freeze at champ select is fixed.** When champ select starts, the app pauses fetching. The fetcher then reports its new status to the app, and that report waited for a lock the League client's handler was still holding, on the same thread, so neither could continue. From then on nothing from the client or the game was handled until the app was restarted. The lock is now released before any such handler runs.
- **Why it wasn't caught:** the built-in simulator and the tests fed champ select and the game in past the client's own handler. A new test sends the client's events through that handler: ready check, champ select on Irelia, a second enemy pick, the game and its end. It fails on 2.1.0 at the first champ-select event and passes now.
- **Champ select no longer waits behind a long database job.** Guessing the enemy's lanes reads how often each champion was faced. That read now waits a quarter of a second at most for the database, then uses the last counts.
- **The log follows the client and the game.** `logs\middleware.log` now has a line for:
  - each change of the League client's connection and phase, and whether champ select is on Irelia (`[client] …`);
  - each matchup the app settles on: lane, opponent and where the opponent came from (`[matchup] …`);
  - each build made, baseline or draft (`[build] …`);
  - the first live game data: the players found, you, and the enemy on your position (`[live] …`), and when the game's data stops or can't be read.
- **No change to results, data or settings.**

## If the app doesn't follow a game
Send `%APPDATA%\irelia-companion\logs\middleware.log` after the game. The lines above show which step is missing.

Not checked in a real game yet: the fix is proven by the new test, which goes through the same handler a real client uses.
