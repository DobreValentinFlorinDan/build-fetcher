# Irelia Companion 2.0.0

**Irelia Companion is now a native app written in Rust. It has the same features and uses the same data as 0.22.0, with a far smaller installer, a third of the memory and faster evaluations. It replaces the withdrawn 1.0.0–1.1.2 builds.**

The installer is per-user (no admin rights). It installs over 0.22.0 (or a 1.x build) and keeps your settings, API key, match data, evaluations and backups in `%APPDATA%\irelia-companion\`. It isn't code-signed yet, so Windows SmartScreen will warn on first run: choose **More info → Run anyway**.

## What changed from 0.22.0
- **One native process instead of Electron.** The server, the model and the evaluation run in the app itself, on threads. There is no shared 4 GB script heap any more, so Evaluate builds no longer needs helper processes to use all your processor's threads.
- **Smaller and lighter.** The installer is about 8 MB instead of about 100 MB. The dashboard and the overlay are shown by WebView2, Microsoft's web view that is part of Windows 10 and 11.
- **Faster evaluations with less memory.** On the same test folder (1,798 games, one thread):

  | | 0.22.0 | 2.0.0 |
  |---|---|---|
  | Full evaluation | 17.9 s | 10.0 s |
  | Quick update | 3.1 s | 1.4 s |
  | Peak memory | 338 MB | 118 MB |
- **The arithmetic is the app's own.** `exp`, `log`, `log1p` and powers are worked out exactly rounded by the app, so results no longer depend on the JavaScript engine, the Windows C library, the processor or the graphics card. 0.22.0's results could change with an Electron update.
- **Use GPU's self-check compares like with like.** The graphics card's kernel and the processor now use the same exactly rounded `exp`, so a card isn't rejected over a last-digit difference.

## Same features, same data
- Everything 0.22.0 does is here: builds and drafts, the live lane tracker, the in-game overlay with its hotkeys and tooltips, Evaluate builds with quick updates, Use GPU, backups and pool sharing, Slim stored data, old-patch archiving and the storage tools.
- **Your data isn't converted.** 2.0.0 reads and writes the same files as 0.22.0. Your first evaluation after installing is a full one, as after every new version.
- **Same results.** On the same data folder, 2.0.0 and 0.22.0 (run in its own Electron 44) give the same numbers, bit for bit:
  - the full evaluation (2,024 numbers) and the quick update (1,866);
  - 200 sampled drafts with every estimate behind them (93,666 numbers).

  Powers are the one place a last digit can differ from 0.22.0 on other data (a few in 10,000 results); verdicts and rankings are checked to be identical.
- **Every test from 0.22.0 has its Rust counterpart** (221 tests).

## Fixed along the way
- **The overlay follows the game after sleep.** The League client's event stream can stay open but stop sending; the app also checks the client every 5 seconds.
- **Show overlay now / Unlock to reposition** open the overlay at once from Settings.
- **Archive old patches** can't hang when it is switched on.
- **The progress bar moves on from fold to fold** instead of starting again at each.

## Policy is unchanged
The app talks only to the Riot API, Data Dragon, the League client (LCU) and the Live Client API, plus your own graphics card's driver when Use GPU is on. It never reads game memory and injects nothing. Nothing leaves your PC unless you choose a backup folder.
