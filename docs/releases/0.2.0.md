# Irelia Companion 0.2.0

Steadier Riot API usage: requests now go out at an even pace instead of in bursts followed by long pauses.

The installer is per-user (no admin rights), lets you choose the install folder, and creates **Irelia Companion** shortcuts in the Start Menu and on the desktop. ## What's new
- **Paced Riot API requests**: requests now go out at an even pace, about one every 1.3 s per Riot server with a development key, instead of ~90 at once followed by a pause of up to 2 minutes. The key's budget is the same (90 requests per 2 minutes), so long scans take about as long as before, but they no longer stall half-way. A short scan no longer finishes in one burst: each request that isn't cached yet takes about 1.3 s. Riot's per-endpoint limits are respected too, and up to 3 requests are in flight at once to hide network latency.
- **Better 429 handling**: when Riot answers "too many requests", the app waits exactly as long as Riot asks and runs a little slower for the next minute. When Riot's own servers are busy, it backs off from that server only and keeps its normal pace.
- **Live rate-limit bars**: the "100 / 120s" and "20 / 1s" bars in **Match Database** fill and drain in real time and show the current pace. The panel and the Dock show whether the app is pacing (with the time until the next request), waiting for Riot (Retry-After) or up to date with no new work.
- **Clearer OTP scan settings**: each Dock slider explains what it does in one line, with more detail behind an "i". Below the sliders, an estimate shows the most API calls and minutes the scan can take at the current pace. Cached data makes most scans cheaper than that.

## First run
1. **⚙ Settings → Riot API key**: paste your key from https://developer.riotgames.com (development keys expire every 24 h).
2. Run an OTP scan in the **Dock**. The estimate under the sliders shows what it will cost before you start.
3. Set League to **Borderless** (Settings → Video → Window Mode).
4. Overlay hotkeys, active only in game: **Shift+Tab** shows or hides it, **Ctrl+Shift+Tab** unlocks it to move. Both can be rebound in Settings.
