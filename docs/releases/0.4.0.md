# Irelia Companion 0.4.0

Much more data behind the builds: whole-patch histories from OTPs and Irelia mains in KR, EUW and NA, every player and a minute-by-minute timeline of each game, remakes and leavers left out, and your own games kept apart for the personal layer to come.

The installer is per-user (no admin rights), lets you choose the install folder, and creates **Irelia Companion** shortcuts in the Start Menu and on the desktop. It isn't code-signed yet, so Windows SmartScreen will warn on first run: choose **More info → Run anyway**.

**Upgrading from 0.3.0:**
- **Your data stays.** Installing over 0.3.0 keeps your settings, API key and match data in `%APPDATA%\irelia-companion\`.
- **The database upgrades itself.** On first start it upgrades in place, and every stored match is rebuilt from the files already on disk: all ten players, the timeline, remakes, leavers and the real lane opponent. This makes no API calls, and **Match Database** shows the progress.
- **Your own scope still wins.** A `scrape.config.json` of your own in that folder keeps overriding the new defaults.

## What's new
- **The whole patch, not the 20 newest games.** Match histories are read from the patch start on each region, 100 ids per call, so an active one-trick's whole patch is collected.
- **More pilots, only active ones:**
  - **Pilots:** Irelia OTPs, plus **Irelia mains** (100k+ points, Irelia among their top 3 champions). Only players who played Irelia this patch are scanned, most recent first.
  - **Harvested games:** another player's top or mid Irelia in a fetched match is kept too, for one extra call.
  - **Build sources:** every game is tagged with its source. Today's builds still use OTP games only.
- **KR, EUW and NA, with Master.** The new default scope is three regions, each with its own request budget, and Challenger, Grandmaster and Master. Each Riot server now works its own queue, so match downloads never wait for ladder or mastery checks. **Match Database** shows what each server is doing.
- **Cleaner games:**
  - **Remakes** are dropped: the remake vote, or a game under 5 minutes.
  - **Leaver games** are dropped: a player who stopped gaining XP, CS and gold.
  - **Lane opponent:** the enemy who actually stood in lane with you; Riot's position labels are wrong in lane swaps.
  - **Patch per region:** each region's current patch comes from its own games, so a region still on the old patch is no longer skipped when Data Dragon moves first.
- **Your games, kept apart.** Your ranked solo and flex Irelia games of this and the last patch are fetched a few minutes after each game ends. They never feed the high-elo builds; they are for the personal layer coming next.
- **Data audit.** **Match Database → Run data audit** measures your data and shows what each fix changes in the lane builds, all without API calls. **Copy report** puts it on the clipboard; it's also saved in `%APPDATA%\irelia-companion\audits`.
- **Settings shows when your API key was saved,** with a reminder that development keys last 24 h.
- **Storage** lists every database table with its size. **Purge stale patches** keeps per-champion totals of the purged games.

## First run
1. **⚙ Settings → Riot API key**: paste a fresh key from https://developer.riotgames.com (development keys expire 24 h after you generate them).
2. Wait for **Match Database** to say "Cache rebuilt", then press **▶ Start fetching**.
3. **Match Database → Run data audit → Copy report** to share what your data looks like.
4. Set League to **Borderless** (Settings → Video → Window Mode). Overlay hotkeys, active only in game: **Shift+Tab** shows or hides it, **Ctrl+Shift+Tab** unlocks it to move.
