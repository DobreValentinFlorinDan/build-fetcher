# Irelia Companion 0.8.0

**Patch memory:** the draft model can learn from the last six patches instead of two, and works out which older games still hold. **Evaluate builds** now tests it on your own games, and it only turns itself on if it wins. Old patches can now be **archived** instead of deleted, and the Riot cache no longer has to grow forever. With patch memory off, builds are exactly as in 0.7.4.

## What's new
- **Patch memory** (Data → Draft model; off until an evaluation finds it better).
  - **What it reads:** games from up to five patches back count as well, each patch back at a fraction of the next. Evaluate builds picks the fraction: 50, 75 or 90 %.
  - **What changed counts less:** for each older game, Data Dragon shows whether Irelia (stats, spells, passive) or the item in question changed between that patch and today's. A changed one counts a quarter as much.
  - **Today's games win disagreements:** an option whose results on today's patch clearly differ from its older results leans on today's. That catches changes Data Dragon doesn't show: hidden changes, bug fixes, other champions' changes.
  - **What it affects:** only the draft-adjusted picks and the live "Next" item. The game-state model, champion profiles, matchup facts, best buy for your gold and Your games stay on today's and the previous patch.
  - **The switch:** **Follow evaluation** (the default), **On** or **Off**. Off is 0.7.4's model.
- **Evaluate builds tests patch memory** in a new section of its report, on the same held-out games as before.
  - It compares the draft model with patch memory against the one without it, with all your games and as if early in a patch (only a quarter of the current patch's games).
  - It turns patch memory on only if it is better with 95 % confidence in one of those, no worse with all games, and predicts results at least as well, with at least 200 games from older patches.
  - The rest of the report is unchanged: on the test databases it matches 0.7.4's to the last digit.
  - It takes a little longer: 34 s on 4,400 test games over six patches.
- **Archive old patches** (Data → Patches).
  - Games of patches older than the six-patch window are compressed into the database's archive instead of deleted.
  - That is about 4.5 KB per game instead of about 13 KB. Nothing is lost, and **Restore archive** puts every game back as it was.
  - Archived games are left out of everything until restored, your own included.
  - To shrink the database file afterwards, use **Compact database** (Settings → Storage). Otherwise new games reuse the space.
- **Clear API cache of old patches** (Settings → Storage).
  - Cached matches and timelines never expire, so the cache grew with every game ever fetched.
  - This deletes the cached files of games older than the six-patch window.
  - The games themselves stay in the database or the archive. Only rebuilding them from the cache would have to download them again.

## Changes
- **Purge stale patches is now Delete old patches.** It keeps the six-patch window instead of only the current and previous patch, and asks before deleting.
- **Patches list:** each patch is labelled current, previous patch, patch memory or outside the window. A region's own current patch counts as current even when Data Dragon is already a patch ahead.
- **Database schema v5** adds one table, `archive`. Nothing else changes.

## Going back to 0.7.4
Install **Irelia-Companion-Setup-0.7.4.exe** from the [0.7.4 release](https://github.com/DobreValentinFlorinDan/irelia-companion/releases/tag/v0.7.4) over 0.8.0. Your settings, API key and games stay. 0.7.4 ignores the archive table and the patch memory setting. Archived games stay in the archive, out of sight, until you install 0.8.0 again and restore them. In 0.7.4, **Purge stale patches** keeps only the current and previous patch again.

## After installing
Nothing to do: patch memory stays off. To find out whether it helps on your data, run **Data → Evaluate builds**. With games from older patches stored, its report says so, and patch memory turns on by itself if it wins.
