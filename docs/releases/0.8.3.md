## Fix: keeping the computer awake
- **What was wrong:** the option used Electron's "prevent app suspension" request.
  - Windows treats it as "keep the system awake" only on PCs without **Modern Standby**.
  - Most current Windows 11 laptops and many desktops have Modern Standby, and on those the PC went to sleep when idle anyway, fetching or not.
  - This was the case since the option arrived in 0.7.4. Nothing in 0.8.x broke it.
- **What it does now:** while fetching runs, a hidden PowerShell holds Windows' own "system required" request. Electron's request stays alongside it.
  - The screen can still turn off.
  - Nothing is installed: PowerShell and the call are part of Windows.
  - It lets go as soon as fetching stops or the app closes.
- **You can see it working:**
  - **In Settings:** a line under the option says whether it is active right now, starting, not needed (fetching stopped), or refused, with the reason.
  - **In the tray:** the icon's tooltip says so too.
  - **For a full check:** while fetching runs, `powercfg /requests` in an administrator terminal lists `powershell.exe` under SYSTEM.
- **New: Keep the screen on too** (off by default): use it if the computer still sleeps while fetching, for example where PowerShell is blocked by policy. Windows always honours it, but the screen stays on.
- **What still sends the computer to sleep:**
  - Sleeping it yourself (lid, power button, Start → Sleep).
  - On battery, a Modern Standby PC drops such requests about five minutes after its sleep timeout. Keep it plugged in for overnight fetching.

## Checked: the other switches
Every other switch was checked and still works:
- **Settings:** show the overlay when a game starts, click-through by default, keep running in the tray.
- **Build tab:** Draft-adjusted / Lane baseline, Top / Mid.
- **Data tab:** Patch memory and Follow the evaluation, archive patches older than the window, Start / Stop fetching.
- **Settings → Storage:** keep the API cache to the six-patch window.

## After installing
Nothing to do: the option stays on. The first time fetching runs, the line in Settings should read "Active now".
