# Irelia Companion 0.7.4

Keeps the computer awake while fetching, recovers from dropped connections within seconds, and fixes what a code review found: a slow Settings → Storage, a slow Your games tab and a memory spike every few minutes while fetching.

The installer is per-user (no admin rights), lets you choose the install folder, and creates **Irelia Companion** shortcuts in the Start Menu and on the desktop. It isn't code-signed yet, so Windows SmartScreen will warn on first run: choose **More info → Run anyway**. Installing over 0.7.3 keeps your settings, API key and match data in `%APPDATA%\irelia-companion\`.

## What's new
- **Keep the computer awake while fetching** (Settings → Desktop & in-game overlay; on by default).
  - While fetching runs, Windows doesn't go to sleep. The screen can still turn off.
  - It ends as soon as fetching stops: when you press Stop, or when a development API key expires 24 hours after you generate it.
  - The tray icon's tooltip says when it is keeping the computer awake.
  - If you put the computer to sleep yourself, it still sleeps.

## Fixes
- **Fetching recovers within seconds after sleep or a network drop.**
  - A request to Riot now gives up after 30 seconds and is tried again on a new connection.
  - Before, a connection that died while the computer slept could leave fetching waiting for minutes.
- **Settings → Storage opens faster** with a large Riot cache.
  - The app checks the cache files' sizes 64 at a time instead of one by one.
  - That is about twice as fast in testing, and likely more on Windows. Clearing the expired cache and moving the data folder benefit too.
- **The Your games tab is about 4× faster to load**, and more with more games.
  - The high-elo item timings were collected in a way whose cost grew with the square of the number of games.
- **A third less memory when the model updates.**
  - While new games arrive, the draft model is rebuilt every few minutes. It now reads the stored games one at a time.
  - On 4,400 test games, the rebuild's memory peak dropped from about 170 MB to 116 MB, with the same speed.
- **The check for new data no longer reads every stored game.** A database index finds the newest game directly; this check runs with every matchup change.

## After installing
Nothing to do. Keeping the computer awake is already on; you can turn it off in Settings.
