# Irelia Companion 0.13.0

**Evaluate builds can now use your NVIDIA graphics card.** A new **Use GPU** switch in **Settings → GPU** turns it on. The results are the same to the last digit, and a GPU log in the same place shows what happened, so you can switch back if anything goes wrong.

## Use GPU (Settings → GPU)
- **What runs on the GPU:** comparing each draft with every stored game, about two fifths of the evaluation's work. Every evaluation thread uses the card. The weighted sums stay on the processor, because their order fixes their rounding.
- **How much faster:** expect a quarter to a third less time on the same threads. This is an estimate: the GPU has not been timed on a real card. **Test GPU** writes to the log how much faster that part runs on your computer.
- **Same results:**
  - Electron's `Math.exp` is correctly rounded, so the GPU computes a correctly rounded exp too.
  - The distances use the same operations in the same order, with nothing fused.
  - The rare game the GPU can't be sure about (about one in 100,000) is worked out on the processor instead.
- **Checked every time:**
  - Before each evaluation, the GPU works out 36,000 test values and each one is compared with the processor's.
  - While the evaluation runs, one pass in 500 is compared too.
  - If anything differs or the GPU fails, that thread carries on with the processor for the rest of the evaluation, and the log says why.
- **Champ select or a game:** the GPU isn't used, so the game has the card. When an evaluation ends or is stopped, everything it put on the card is freed.
- **Needs:**
  - an NVIDIA card from 2014 or later (compute capability 5.2+);
  - a driver with CUDA 12.0 or later. Your RTX 4050's driver qualifies.
  
  Nothing else to install. Without such a card, or with Use GPU off (the default), everything runs on the processor as before.

## The GPU log
- **Where:** below the switch in Settings → GPU, with **Test GPU**, **Copy log** and **Clear log**. It is saved in `%APPDATA%\irelia-companion\gpu.log`.
- **What it shows:**
  - the card, its memory and driver;
  - each check's result;
  - per evaluation, how many passes ran on the GPU and how long each took;
  - anything that made it go back to the processor.
- **If something looks wrong:** switch Use GPU off. The next evaluation runs on the processor only.

## How it was checked
- **No GPU here:** I couldn't run the kernel on a real GPU. Instead, it ran on the processor through a stand-in for the NVIDIA driver, under Electron 44.
- **Same values:** 434,000 similarities and a 3-thread evaluation matched the processor to the last digit.
- **First run on your card:** the check on the real GPU happens there, before it is used.

## Also
- **New dependency: koffi** (MIT, a C function interface for Node.js with prebuilt modules). It is how the app reaches the NVIDIA driver without a native build step. It is only loaded with Use GPU on.
- **`npm run gpu:ptx`:** rebuilds the kernel's PTX from `server/gpu/similarities.cu` with NVIDIA's runtime compiler.
