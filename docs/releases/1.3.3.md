# Build Fetcher 1.3.3

**1.3.3 lets the calibration correct each part of the game separately, so an improved model is no longer rejected
because one time window got worse.**

The installer is per user, with no admin rights. It installs over any earlier version and keeps your settings, key,
games and model in `%APPDATA%\build-fetcher\`. It isn't code-signed yet, so Windows SmartScreen warns on first run:
choose **More info → Run anyway**.

## Fixed
- **Updates kept failing on the 30+ minute window.**
  - **What happened:** on a user's games, the correction fixed the 10–30 minute windows (calibration error 0.12–0.14
    down to 0.02–0.05). The 30+ window went from 0.04 to 0.12–0.14, so every check still failed, although the update
    predicted far better (log loss 0.62 against 0.69).
  - **Cause:** the correction was one straight line over game time. The model needed its confidence ×2 from 10 to 30
    minutes and ×1 after 30, and a line can only keep rising, so it reached about ×2.8 late in the game.
  - **Now:** after the line, each window (0–10, 10–20, 20–30, 30+ minutes) gets its own factor. A window's factor
    changes only when its held-out games show a significant need, with at least 100 matches in that window and the
    same kind of statistical test as the line.
  - The guardrail is unchanged. The ranking of options is unchanged: only the percentages move.
- Each check's log line now also shows the four window factors.

## Measured
On Linux, synthetic data:
- 167 Rust tests and 7 web tests pass.
- **A new test copies the user's pattern** (×2 needed from 10 to 30 minutes, ×1 after): at 35 minutes the line alone
  gives ×1.30, the line with window factors ×1.07.
- **Where a line was already right,** the window factors stay at 1. Continuous learning on synthetic data is
  unchanged: 6 of 10 checks accepted on 1,500 new games, log loss 0.4921.

## Not verified before release
- Whether your next checks pass. Based on your log, the 30+ window should come back under its bound.
- Models saved by 1.3.3 can't be read by 1.3.2 or earlier (checkpoint format 3). Older models load in 1.3.3.
