## The fix 0.21.1 meant
- **What went wrong:**
  - 0.21.1 checked every one-trick again when their server moved to a new patch.
  - But the app keeps Riot's mastery answers on disk for 3 days, so that check read the answer stored before the patch and learned nothing new.
  - The one-tricks kept looking as if they hadn't played Irelia since the patch began. Their match history wasn't read, and the hosts stayed at **Up to date – no new work**.
  - On 16.22 that left 59 games across five servers after more than a day, against about 2,700 a day on 16.21.
- **Now:** a check made because of a new patch asks Riot again whenever the stored answer is from before the patch. Answers stored since the patch began are still reused.
- **Undoing 0.21.1's checks:** the one-tricks 0.21.1 checked from old answers count as checked, so on its own the fix would leave them for 3 days. On each server, once per patch, one-tricks checked since the patch began whose last Irelia game is still before it are checked once more. The log says how many (`checking N pilots' Irelia activity again`).
- **What you'll see after updating:**
  - each server shows **Refreshing pilot activity** for a few minutes;
  - then the regional hosts (asia, europe, americas) show **Reading … match history**;
  - the 16.22 count climbs.
- **Cost:** one mastery request per one-trick per patch, on each server's own host. Its budget is separate from match downloads, so fetching matches doesn't slow down.

## Also
- Evaluations and backups are unchanged from 0.21.1. As with every new version, your first evaluation after installing is a full one, and an evaluation only travels with a backup between computers on the same version.
- Data and policy are unchanged: Riot API and Data Dragon only, nothing leaves your PC unless you choose a backup folder, and no new dependencies or schema changes.
