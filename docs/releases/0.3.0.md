# Irelia Companion 0.3.0

Builds for mid as well as top, and an overlay that ticks the boots and items you actually bought.

The installer is per-user (no admin rights), lets you choose the install folder, and creates **Irelia Companion** shortcuts in the Start Menu and on the desktop. It isn't code-signed yet, so Windows SmartScreen will warn on first run: choose **More info → Run anyway**. Installing over 0.2.0 keeps your settings, API key and match data in `%APPDATA%\irelia-companion\`. Games you already collected work for both lanes without a re-download, and saved Dock scans show Top and Mid builds the first time you open them.

## What's new
- **Top and mid builds**: runes, items and skill order are now built from the games Irelia OTPs played in your lane. While a lane has fewer than 30 games on the patch, the other lane's games are blended in at a low weight, and the build says so. Jungle, bot and support games are never used.
- **Your lane, detected**: the Draft dashboard follows your assigned lane in champ select and your position in game, and shows where the lane came from. The new **Top / Mid** switch overrides it until the draft and game end. Blind pick has no assigned lane, so the lane you picked last is used.
- **Better lane-opponent guess**: the likely opponent is now the enemy pick Irelia faced most often **in your lane**, else the first Fighter or Tank for top and Mage or Assassin for mid. Top and mid never get the same pick, so while only one enemy has locked in, only the lane it fits shows a suggestion. An enemy whose role is shown as jungle, bot or support is never guessed. It only uses the picks everyone in champ select can see.
- **Dock and overlay know the lane**: the Dock shows Top / Mid tabs with each lane's game count, the overlay titles the matchup **Top · vs Darius** or **Mid · vs Syndra**, and Match Database splits each patch's games into top and mid.
- **Overlay ticks what you bought**: owned items are ticked in any purchase order, including:
  - tier-3 boots (Armored Advance, Gunmetal Greaves, …) count as the tier-2 boots they came from (✓);
  - different boots, or an item that shares a unique passive with the planned one (Maw instead of Sterak's), fill the slot and are marked ⇄, so **Next** never points at an item the shop won't sell you;
  - components show a dashed border, and **Next** shows the gold still needed.
- **Fixed**: the overlay sometimes ticked nothing when the game didn't report your full Riot ID. It now finds you the same way the lane tracker does.

## First run
1. **⚙ Settings → Riot API key**: paste your key from https://developer.riotgames.com (development keys expire every 24 h).
2. Run an OTP scan in the **Dock**. The estimate under the sliders shows what it will cost before you start.
3. Set League to **Borderless** (Settings → Video → Window Mode).
4. Overlay hotkeys, active only in game: **Shift+Tab** shows or hides it, **Ctrl+Shift+Tab** unlocks it to move. Both can be rebound in Settings.
