# Build Fetcher 1.3.2

**1.3.2 fixes the team network's progress, which stood still, and shows on every check whether the calibration
correction ran.**

## Fixed
- **The team network's count stood still** (for example at 1,200 of 200,000) while new games with a timeline came in.
  - **Cause:** the count was the larger of "games stored at start-up" and "games learnt since". New games only showed
    once they alone passed the stored ones.
  - **Now:** the stored games count once, and every game with a timeline learnt after that adds to them.
  - **Small over-count:** games stored but not yet learnt at start-up can be counted twice, usually a few hundred.

## New
- **Every check now says whether the calibration correction ran:** "calibration: N held-out matches in the pool;
  temperature A + B per 10 min (…)". The part in brackets says one of three things:
  - **not fitted yet:** fewer than 250 matches;
  - **fitted, no significant change:** the correction ran but kept the current values;
  - **fitted:** the correction ran and changed them.
  Before, only accepted updates showed it.

## Measured
- 166 Rust tests and 7 web tests pass. The team network's test now also checks that the count grows with each game
  learnt, and that every check logs its calibration.
