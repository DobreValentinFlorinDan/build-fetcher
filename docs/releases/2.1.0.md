# Irelia Companion 2.1.0

**2.1.0 is faster: evaluations, the model build at start-up and reading stored games all take less time. Results are identical to 2.0.0's and there are no data or settings changes.**

The installer is per-user (no admin rights). It installs over 2.0.0 or 0.22.0 and keeps your settings, API key, match data, evaluations and backups in `%APPDATA%\irelia-companion\`. It isn't code-signed yet, so Windows SmartScreen will warn on first run: choose **More info → Run anyway**.

## What's faster
- **Comparing a draft with every stored game** (the largest part of Evaluate builds on a big pool): 28.7 ns a game instead of 44.5 ns. Four games are worked out side by side, each with its own sum in the same order as before, so every number is the same.
- **`exp`:** 12.1 ns instead of 15.0 ns on processors with FMA (any from the last ten years). It is still exactly rounded, so the result is the same with or without it; the tests compare the two on 1,020,040 values.
- **Reading stored games:** each game's timeline is read straight into the model's form instead of through a general JSON tree. On the test folder that step takes 269 ms instead of 419 ms. The model build when the app starts reads games the same way.
- **Memory allocation:** the app uses the mimalloc allocator (open source, MIT licence). The full evaluation on the test folder went from about 10 s to about 9 s with this alone. It keeps more memory in reserve: the evaluation's peak on that folder is 169 MB instead of 118 MB.

On the test folder (1,798 games, one thread) the full evaluation takes about 8 s instead of about 10 s. The gain should be larger on a large pool, where the draft comparison is most of the work; that is not measured here.

## Same results
- Against 0.22.0 run in Electron 44, on the same data folder, every number is still identical bit for bit: the full evaluation (2,024 numbers), the quick update (1,866) and 200 sampled drafts (93,666).
- 222 tests pass. A new one checks that the new timeline reader and the old one give the same result on a real timeline and on more than 100 damaged ones.

## Tried and left out
- Full link-time optimization and eight games at a time in the comparison measured no faster, so they aren't in.

## No data or settings changes
Updating in place keeps everything. Your first evaluation after installing is a full one, as after every new version.
