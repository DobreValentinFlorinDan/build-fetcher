## Blending two computers' pools
- **The fix:** each computer keeps the 3 newest backups it made in the backup folder. Before, it counted the other computer's backups too, so a computer backing up weekly could delete the other one's backup from the shared folder (never from that computer itself).
- **How to blend:**
  1. On both computers, open the Data tab → **Backup** → **Choose a backup folder…**, and pick the same folder (for example in Google Drive).
  2. Click **Back up now** on each.
  3. Each computer then offers the other one's newest backup: click **Import**.
- **What an import does:** it adds only the games that computer doesn't have yet, and the one-tricks and mains it doesn't follow yet. A game both computers fetched is stored once. Nothing is replaced or deleted. After importing both ways, both computers hold every game either one had.
- **Afterwards:** both computers keep fetching on their own. Import the other's newer backup whenever it's offered (weekly, or after **Back up now**).
- The first evaluation after an import that adds many games is a full one (over 20 % new games).
