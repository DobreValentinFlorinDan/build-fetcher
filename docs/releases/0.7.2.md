# Irelia Companion 0.7.2

"Evaluating… (about a minute)" no longer looks stuck. The evaluation is many times faster, the Data tab shows how far it has got, and you can cancel it.

The installer is per-user (no admin rights), lets you choose the install folder, and creates **Irelia Companion** shortcuts in the Start Menu and on the desktop. It isn't code-signed yet, so Windows SmartScreen will warn on first run: choose **More info → Run anyway**. Installing over 0.7.1 keeps your settings, API key and match data in `%APPDATA%\irelia-companion\`.

## Fixes
- **Evaluate builds no longer seems to hang.**
  - **Why it hung:** the evaluation compares every stored game with every other one, so its time grew with the square of the number of games. "About a minute" was true for about a thousand games. With 4,400 it took over six minutes, and with more it ran for tens of minutes with no sign of progress.
  - **Much faster, same report:** it now takes 41 s for 4,400 games instead of 6.4 min, and the gap grows with more games. The results are the same as before, to the last digit. The minute-by-minute "Next" stability replay uses at most 500 games (an even sample); it is a side figure and doesn't decide the default build.
  - **Progress, time and Cancel:** the Data tab shows the step it is on ("Step 9 of 18: Comparing builds"), a progress bar and the time so far. **Cancel** stops it and changes nothing.
  - **Switching tabs is safe:** the progress and the report stay when you switch tabs and come back. The report also says when it finished and how long it took.
- **Data Dragon:** a stalled download now gives up after 30 seconds instead of waiting forever.

## After installing
Nothing to do. Press **Data → Evaluate builds** again to see it finish.
