# Irelia Companion 0.7.3

Uses less memory: about a third less while **Evaluate builds** runs, a smaller model kept between builds, and the dashboard's memory freed when you close it to the tray.

The installer is per-user (no admin rights), lets you choose the install folder, and creates **Irelia Companion** shortcuts in the Start Menu and on the desktop. It isn't code-signed yet, so Windows SmartScreen will warn on first run: choose **More info → Run anyway**. Installing over 0.7.2 keeps your settings, API key and match data in `%APPDATA%\irelia-companion\`.

## Memory
Measured on 4,400 stored games (test data). The figures are for the app's background process, which holds the data, the model and fetching.

| | 0.7.2 | 0.7.3 |
|---|---|---|
| While **Evaluate builds** runs (peak) | 1,025 MB | 696 MB |
| Idle | about 240 MB | about 230 MB |
| Draft model kept in memory | 64 MB | 48 MB |

- **Evaluate builds** was the biggest user. It holds one part of the test (a "fold") at a time instead of all five. It no longer copies every game-state frame for each model it tries, and it lets go of the game timelines it won't replay. The results are the same, to the last digit, and it is as fast as before. Memory returns to normal within a minute after it ends.
- **The draft model** drops data only its build needs, once the build is done.
- **Lane builds are reused:** the lane build for a lane and opponent is kept until new games arrive. Going back to a matchup no longer re-reads every stored game, so it is faster too.
- **Closing to the tray frees the dashboard:** closing the window with "Keep running in the tray" on now closes it instead of hiding it, which frees the memory of its whole Chromium page (not part of the table above). Opening it from the tray takes a second, and the tab you were on comes back. The overlay already existed only during games.

The total in Task Manager also includes Electron's own processes (window, graphics) and grows with the number of stored games.
