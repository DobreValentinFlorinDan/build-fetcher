# Build Fetcher 1.1.1

**1.1.1 fixes the build rankings: options with a handful of games no longer outrank options with hundreds. It also makes the model's scores trustworthy from the start.**

## Fixed: build rankings
On Ahri mid, five Summon Aery rune pages with 1–10 games each were ranked above Deathfire Touch with 181 games. Exhaust + Ignite with 1 game sat above Flash + Ignite with 1,063. Three causes:
- **Other roles leaked in.** An option's estimate for one role was pulled toward its estimate over *all* the champion's roles. Summon Aery is strong on support Ahri, so a mid Aery page with 1 game inherited that.
  - **Now:** each role stands on its own games. Other roles help only when the role itself has fewer than 200 games of the champion.
- **Small samples counted too much.** 25 games are too few to tell a real edge from luck.
  - **Now:** estimates are shrunk toward "no effect" at a strength set by how noisy a win rate is (about 250 games' worth). A few lucky games barely move an option, and a thousand games move it most of the way.
- **The ranking ignored how much evidence an option had.**
  - **Now:** options with enough games in the role (30 or more) are ranked first, by their estimate. Thin options follow, most played first, flagged "thin data". In-game next buys use the same rule.

The display changed too. Each option now shows the games and win rate **in that role, as played**, and the estimated effect, labelled "est.". Before, a thin option showed counts from all roles and an estimate labelled "% win".

## Fixed: model scores
- **The Model page's "Games" column counted examples, not matches.** An example is one player at one moment of a match; a match gives up to 70. "150" meant about 2–3 matches.
  - The column is now **Test matches**; hover it to see the examples.
  - Versions scored before 1.1.1 show "—" until they are scored again.
- **Early scores rested on a handful of matches.** The test set (held-out matches the model never trains on) only takes games with a timeline. Before, 1 in 10 of those went to it. Now 1 in 3 goes to it until it holds 300 matches, then 1 in 10.
- **Scores were never updated.** While waiting for new games (idle, at most once an hour), the model in force is now scored again on the whole, larger test set. Only the numbers shown change, not the model, and the learning log says what changed.

## Measured
On Linux, synthetic data:
- 157 Rust tests pass.

- The planted effects are still found. Their estimated sizes are smaller, because the stronger shrinkage is deliberately more conservative.
