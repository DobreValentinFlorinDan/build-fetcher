# Irelia Companion 0.21.0

**A backup now carries its computer's evaluation, so the computer importing it uses those verdicts at once and only evaluates the games the other one didn't have.**

## The evaluation goes with the backup
- **Before:** a backup held the games only. The computer importing it had to evaluate the whole pool again: over an hour on a large one.
- **Now:** a backup also holds the computer's last evaluation:
  - its verdicts;
  - every evaluated game's measurements;
  - which games it had when it evaluated.
- **On import,** the other computer uses that evaluation when it fits:
  - its verdicts apply at once;
  - its report is saved as `eval-imported-….txt` next to your reports;
  - the next evaluation is a **quick update** that measures only the games the other computer didn't have, such as the ones this computer fetched itself.
- **When it isn't used** (the import says why):
  - The two computers run different versions, Data Dragon versions or evaluation settings: update both to the same version.
  - This computer's own evaluation already covers as many games or more: it keeps its own.
  - Games the evaluation measured are missing from this pool.
- **A full evaluation still comes when the usual rules call for one:** over 20 % more games, a new patch, or the evaluation over a week old.

## Blending two computers (with 0.20.1)
1. Update both computers to 0.21.0.
2. On the computer with the large pool, run one evaluation (a full one, since the version is new). Then click **Back up now**.
3. On the other computer, choose the same backup folder and **Import** the backup it offers. It adds the games it doesn't have and takes over the evaluation. Its own fetched games are measured by the next quick update.
4. To get the other computer's games onto the large one, back up there and import on the large one. Its own, larger evaluation stays, and the new games are measured by a quick update (a full evaluation if they are over 20 % of its games).

## Also
- Data and policy are unchanged: Riot API and Data Dragon only, nothing leaves your PC unless you choose a backup folder, and no new dependencies or schema changes.
- A backup made with an older version still imports. It just carries no evaluation.
