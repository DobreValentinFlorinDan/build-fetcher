# Irelia Companion 0.8.2

Fixes from a second review of 0.8.0 and 0.8.1. Nothing changes in how builds are chosen with patch memory off.

The installer is per-user (no admin rights), lets you choose the install folder, and creates **Irelia Companion** shortcuts in the Start Menu and on the desktop. It isn't code-signed yet, so Windows SmartScreen will warn on first run: choose **More info → Run anyway**. Installing over 0.8.1 keeps your settings, API key and match data in `%APPDATA%\irelia-companion\`.

## Fixes
- **Patch memory on patch day.** When a new patch comes out, Data Dragon publishes it before the servers switch.
  - For those hours or days, patch memory had no Data Dragon files for the oldest patch in its window. Its games counted as "unknown change" instead of being checked for Irelia and item changes.
  - The app now keeps the files of one patch more, so every patch in the window is checked.
- **The post-game review with patch memory on.** It compared your item timings with high-elo games from all six patches, while Your games compared with today's and the previous patch only. Both now use the same two patches.
- **The Data tab's "On 16.x" count.** It counted your server's own patch but showed Data Dragon's patch as the label, so on patch day it could read "On 16.20" next to the 16.19 count. The label now shows the patch actually counted.
- **Archive and cache switches.** Their automatic catch-up, when a patch leaves the window, now waits until champ select or the game is over. Its batches run alongside the overlay's updates.
- **A small leak while fetching.** After every game the app keeps watching for your new match a few times; it also kept those timers in a list nobody read, which grew with every game played.

## Faster
- **Model builds** no longer make a copy of each stored game state to compute the best buy for your gold.
- **Matchup facts, Your games and the best buy** no longer copy the model's game list on every request when patch memory is off.

## After installing
Nothing to do. On its first start the app downloads Data Dragon's item and Irelia files for one more patch (about 0.7 MB, from Data Dragon only).
