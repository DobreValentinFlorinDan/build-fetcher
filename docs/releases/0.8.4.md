# Irelia Companion 0.8.4

With **Follow the evaluation** on, **Evaluate builds** now also runs by itself, so its verdict on patch memory keeps up with your games. The Data tab's wording about what updates when is fixed too.

The installer is per-user (no admin rights), lets you choose the install folder, and creates **Irelia Companion** shortcuts in the Start Menu and on the desktop. Installing over 0.8.3 keeps your settings, API key and match data in `%APPDATA%\irelia-companion\`.

## New: Evaluate builds runs by itself
- **Why:** with Follow the evaluation on, the last evaluation decides whether patch memory is on. Until now it ran only when you clicked, so that verdict stayed as old as your last click while new games came in.
- **When it runs:**
  - After 300 new games since the last evaluation, or once games of a new patch are stored.
  - At most every 6 hours, counted from the last evaluation, yours or the app's.
  - Only after 10 minutes without champ select or a game.
- **If champ select or a game starts** while it runs, it stops at once and nothing changes. It starts over after the next quiet 10 minutes.
- **What it costs:** the same as clicking, in its own thread: seconds to a few minutes, with fetching carrying on. No API calls.
- **What it can change:** the same as a click. Patch memory, if Follow the evaluation is on. The default build mode, if you never chose Draft-adjusted or Lane baseline yourself. The bandwidth and prior.
- **Its reports** are saved next to yours as `eval-auto-….txt`. Only the newest 20 automatic ones are kept; the reports of evaluations you start are never deleted.
- **Follow the evaluation off:** Evaluate builds runs only when you click it, as before.

## The Data tab
- **Under Evaluate builds:** a line says when the next automatic evaluation is due, for example "Due (312 new games): it runs at 21:05", or how many new games there are so far.
- **A running automatic evaluation** is labelled "Automatic evaluation (312 new games)". You can cancel it like your own; the app then tries again 6 hours after it started, at the earliest.
- **Wording fix:** "It is rebuilt from new games every few minutes" sat under the patch memory switches and read as if it meant the evaluation. It meant the draft model, and now says so:
  - **The draft model** is rebuilt from new games every few minutes.
  - **The evaluation** runs when you click Evaluate builds, or by itself as above. Its result stays until the next one.
  - **Bandwidth and prior** are said to come from the last evaluation, or to be the defaults before the first one.

## After installing
Nothing to do. If Follow the evaluation is on and 300 games have come in since your last evaluation, or a new patch has, the first automatic evaluation runs about 10 minutes after the app starts, unless champ select or a game is on.
