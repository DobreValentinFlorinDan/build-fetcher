## The first days of a patch
- **The problem:**
  - Fetching only reads the match history of one-tricks whose last Irelia game is after their server's current patch began.
  - It learns that from a mastery check, which it repeats for each one-trick every 3 days.
  - When a server moved to a new patch, almost every one-trick's last check was from before it, so they were skipped until their next check came round.
  - For up to 3 days, the Data tab could show **Up to date – no new work** with only a handful of games on the new patch.
- **Now:** when a server moves to a new patch, every one-trick checked before the patch began is checked again right away (**Refreshing pilot activity**). Those who have played Irelia since are read the same day.
- **Cost:** one mastery request per one-trick per patch. It goes to each server's own host, whose request budget is separate from match downloads, so fetching matches doesn't slow down.

## Also
- Evaluations, backups and the evaluation that travels with them are unchanged from 0.21.0. A backup made with 0.21.0 imports into 0.21.1, but its evaluation is only taken by a computer running the same version, so update both.
- Data and policy are unchanged: Riot API and Data Dragon only, nothing leaves your PC unless you choose a backup folder, and no new dependencies or schema changes.
