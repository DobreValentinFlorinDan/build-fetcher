# Build Fetcher 1.1.0

**1.1.0 adds Export and Import (move Build Fetcher to another PC, or keep a copy) and Pause / Resume buttons for fetching and learning. It also fixes the learner so its first model arrives reliably.**

The installer is per user, with no admin rights. It installs over 1.0.0 and keeps your settings, key, games and model in `%APPDATA%\build-fetcher\`. It isn't code-signed yet, so Windows SmartScreen warns on first run: choose **More info → Run anyway**.

## What's new
- **Export and Import** (Settings → Storage).
  - **Export…** writes one zip with your settings, games, counts and model. Fetching and learning go on meanwhile. Your Riot API key is included only if you tick *Include my Riot API key*. Data Dragon and logs are left out.
  - **Import…** checks the zip and applies it when Build Fetcher restarts (**Restart now**).
    - The data it replaces is kept in `%APPDATA%\build-fetcher\before-import` until the next import, so a wrong import can be undone.
    - Without a key in the zip, the PC keeps its own key.
    - A zip that isn't a Build Fetcher backup, comes from a newer version, holds a damaged database or tries to write outside its folder is refused before anything changes.
- **Pause / Resume fetching** (Fetching page, and Settings → Learning).
  - Pausing stops new requests at once and cancels those in flight.
  - The choice is kept after a restart.
  - Fetching still pauses on its own in champ select and in game.
- **Pause / Resume learning** (Model page, and Settings → Learning). Pausing stops an update in progress at its next step; nothing half-trained is kept.

## Fixed
- **The first model could take a very long time to appear.**
  - **Cause:** when the PC stayed idle while games were being fetched, the learner trained on the few games that had arrived in the last seconds. Each tiny update was rejected, and those games then counted as used.
  - **Now:**
    - The first update waits for 2,000 new games and at least 100 held-out games to check it on. Later updates wait for 500 games, or 6 hours, whichever comes first.
    - Games stay unread until then.
    - The Model page says what it is waiting for, for example "Waiting for 2000 new games before the first update (1234 so far)".
  - Clean-up now runs only after real updates.
